Forecast Ops map data

Data packages for the Forecast Ops model maps: NOAA HRRR (3 km) for the Cincinnati Tri-State, on the model's native grid. Model guidance only, not an official forecast.

Run list: data/index.json. Each run lives under data/hrrr/<YYYYMMDDHH>/ with a manifest.json describing every field, unit, accumulation interval, missing hour and the exact NOAA byte ranges used.

Source: NOAA NCEP HRRR via the NOAA Open Data Dissemination program on AWS (U.S. Government work).
